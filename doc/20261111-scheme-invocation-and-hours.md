# 2026-11-11 培养方案调用范围与排课调整

## 业务规则

1. 总学时与学时预警只累计学时，不把周换算为学时；训练课目、实践项目的学时与周数分别显示。
2. 实践训练课目安排包含“贯穿四年”时，默认排在第八学期。修改保存时覆盖已有手动排课；同一课目多条执行安排合并到第八学期。来源库修改同时同步调用副本的安排，避免重新生成后恢复旧学期。
3. 专业课程、军士任职基础/任职岗位、训练课目及实践项目支持按专业类调用。请求保留 majorId，subMajorId 明确为 null。方向级调用仍发送具体 subMajorId。
4. 专业类调用动态适用于培养方案该专业类下的专业方向，后续新增方向无需重新调用。
5. 已有单方向调用不删除。相同来源、模块及专业范围下，某方向已有专属副本时，该方向的排课与导出使用专属副本；其余方向使用专业类通用副本，避免重复展示。
6. 源课程的 majorIds/subMajorIds 是源库适用范围，不代表培养方案调用范围，不能拿来过滤调用副本。

## 接口

- `POST /csys/course/invoke` 沿用原路径，专业类调用明确传 `majorId` 和 `subMajorId: null`。
- 课程传课程模块及子模块；训练课目传 `location`；实践项目保留原项目层级。
- 方案课程、执行排课及 Word/XLS 导出统一采用专业方向优先、专业类回退规则。
- 首页概况统计 `trainingHours`、`practicalHours` 只统计学时，增加 `trainingWeeks`、`practicalWeeks` 返回周数。
